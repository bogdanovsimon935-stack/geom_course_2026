# Домашние задания

Каждое домашнее задание выполняется в отдельной папке `hwNN`, где `NN` — номер задания с ведущим нулём.

## Правила

1. Перед началом работы выполните `git pull`.
2. Не изменяйте файлы чужих заданий без необходимости.
3. Проверяйте программу из корня репозитория.
4. Для законченного этапа делайте отдельный содержательный коммит.
5. Перед сдачей выполните `git push` и откройте репозиторий на GitHub.
