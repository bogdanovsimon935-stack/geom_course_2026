# Ответы на вопросы к ДЗ №1
1. Чем DataFrame отличается от массива NumPy?
NumPy - матрица их чисел (однородных данных). DataFrame - таблица с разными типами данных со строгими именами колонок.

2. Что означают две величины в shape массива (13, 2)?
(13) - колиство строк (2) - количество столбцов

3. Почему pressure * 1_000_000 не требует цикла for?
Так - как Pandas и NumPy используют векторные вычисления, операция применяется ко всем элементам массива одновременно, этот метод работает быстрее, чем for.

4. Что выбирает срез array[::2]?
Он берет каждый второй элемент массива 0 -> 2 -> 4 -> 6

5. Что содержится в логической маске?
Функции истинности (True и False)

6. Зачем после сохранения загружать массив обратно?
Для проверки ценности данных, Проверка записи на жесткий диск.

7. Какие файлы являются исходными, а какие создаются программой?

Исходные:
* wells.csv: Содержит координаты и измерения давления для конкретной скважины.
* layers.xlsx: Описывает свойства (толщину, пористость) одного геологического слоя.
* pumping_test.txt: Представляет собой замер изменения давления во времени.

Создаваемые файлы: 
* wells_clean.csv: чистая таблица скважин.
* table_summary.xlsx: файл со сводной статистикой
* pressure_matrix.npy: файл с двухмерной матрицей
* pressure_cube.npz: архив с трехмерным кодом данных
* results.txt: финальный текстовый отчет
