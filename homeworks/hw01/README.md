**Темы:** Python, NumPy, Pandas, чтение и сохранение данных.

В научной работе данные редко приходят в одном удобном файле. Часть измерений может храниться в CSV, часть — в Excel, часть — в текстовой таблице. Прежде чем строить графики, нужно научиться:

- открыть каждый файл с помощью программы;
- понять, что находится в строках и столбцах;

- выбрать нужные строки;
- преобразовать таблицу в массив NumPy;
- сохранить результат так, чтобы программу можно было запустить повторно.

## 5. Выполните вычисления для столбцов

### Что такое векторизованная операция

Векторизованная операция выполняет одно действие сразу для всех элементов столбца или массива.

Пример:

```python
pressure_pa = wells_clean["pressure_mpa"] * 1_000_000
```

Эта одна строка переводит все значения давления из мегапаскалей в паскали. Цикл `for` для такого вычисления не нужен.

Добавьте в `wells_clean` следующие столбцы по готовым формулам.

### 5.1. Перевод единиц

```text
pressure_pa = pressure_mpa × 1 000 000
```

### 5.2. Разность давлений

Пусть опорное давление равно `12 МПа`:

```text
pressure_difference_mpa = 12 − pressure_mpa
```

### 5.3. Относительное изменение в процентах

```text
relative_change_percent = pressure_difference_mpa / 12 × 100
```

Так в работе появятся сложение, вычитание, умножение и деление массивов. Никакой физической формулы здесь выводить не нужно.

## 6. Используйте математические функции NumPy

Все формулы в этом разделе даны полностью. Задача — правильно применить функции к столбцам.

### Синус и косинус: проверка координат

Азимут хранится в градусах, но NumPy принимает угол в радианах:

```text
theta_rad = azimuth_deg × pi / 180
x_check = radius_m × cos(theta_rad)
y_check = radius_m × sin(theta_rad)
```

Вычислите `x_check` и `y_check`. Сравните их с `x_m` и `y_m` через `numpy.allclose` с допуском `atol=0.02`.

### Логарифм: преобразование расстояния

```text
log_radius = ln(radius_m)
```

Используйте `numpy.log`. Объяснять его физический смысл не требуется.

### Экспонента: учебная последовательность

Для времени из `pumping_test.txt` вычислите:

```text
decay = exp(−time_h / 36)
```

Используйте `numpy.exp`. Проверьте, что первое значение равно примерно `1`, а последующие значения уменьшаются.

## 8. Выбор элементов

### Индекс

Индекс — номер позиции элемента. В Python нумерация начинается с нуля:

```python
pressure = wells_clean["pressure_mpa"].to_numpy()
pressure[0]       # первое значение
pressure[-1]      # последнее значение
```

### Срез

Срез — выбор нескольких соседних элементов:

```python
pressure[:3]      # первые три значения
pressure[2:5]     # значения с индексами 2, 3 и 4
pressure[::2]     # каждое второе значение
```

### Логическая маска

Логическая маска — массив значений `True` и `False`. Он показывает, какие строки нужно оставить.

```python
mask = pressure < pressure.mean()
selected = pressure[mask]
```

4. давления ниже среднего;

## 10. Создайте трёхмерный массив

Трёхмерный массив можно представить как несколько таблиц одинакового размера, сложенных в стопку.

Создайте две версии:

Ожидаемая форма `pressure_cube`:


- столбец давления в скважине для обеих таблиц: `pressure_cube[:, :, 1]`.

## 11. Выполните транспонирование и изменение формы

### Транспонирование

Транспонирование меняет местами строки и столбцы:

```python
pressure_transposed = pressure_matrix.T
```

Форма изменится с `(13, 2)` на `(2, 13)`.

### Reshape

`reshape` меняет форму массива, не меняя порядок и количество элементов:

```python
flat = pressure_cube.reshape(-1)
restored = flat.reshape(pressure_cube.shape)
```

Проверьте восстановление:

```python
assert np.allclose(restored, pressure_cube)
```

### Ознакомительный пример класса

Класс — описание объекта, в котором данные и действия над ними собраны вместе. Самостоятельно проектировать класс в этом задании не требуется. Добавьте в `data_utils.py` готовый пример:

```python
class DatasetInfo:
    def __init__(self, name, table):
        self.name = name

    def describe(self):
        return f"{self.name}: {self.rows} строк, {self.columns} столбцов"
```
